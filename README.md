# Zomato Bangalore Restaurant Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on Bangalore restaurant data collected from Zomato. The goal of the project is to analyze customer preferences, restaurant trends, pricing behavior and factors affecting restaurant popularity and ratings.

The project focuses on transforming messy real-world data into meaningful business insights using Python and data analytics techniques.

---

## Business Problem

Restaurants and food delivery platforms generate massive amounts of customer and restaurant data. Analyzing this data can help businesses:

* Identify high-demand restaurant locations
* Understand customer cuisine preferences
* Evaluate pricing strategies
* Analyze online ordering trends
* Improve customer engagement and satisfaction

This project aims to solve these business problems through data analysis and visualization.

## Data Cleaning Performed

The raw dataset contained several real-world data quality issues including:

* Missing values
* Duplicate records
* Corrupted text encoding
* Inconsistent rating formats
* Numeric columns stored as text

Cleaning steps included:

* Handling null values
* Removing duplicates
* Converting ratings and cost columns into numeric format
* Cleaning encoding issues
* Removing unnecessary columns

## Exploratory Data Analysis

The project includes analysis on:

* Restaurant distribution by location
* Popular cuisines
* Online ordering trends
* Rating distribution
* Cost vs Rating relationship
* Most popular restaurants based on customer votes

---

## Key Insights

* BTM contains the highest concentration of restaurants in Bangalore.
* North Indian cuisine dominates the restaurant ecosystem.
* Around 65% restaurants support online ordering.
* Most restaurant ratings lie between 3.5 and 4.2.
* Higher pricing does not necessarily guarantee higher ratings.
* Byg Brewski, Toit and Truffles received the highest customer engagement.
